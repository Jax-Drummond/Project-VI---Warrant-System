\chapter{👮 Officer Warrant System }
\hypertarget{md__r_e_a_d_m_e}{}\label{md__r_e_a_d_m_e}\index{👮 Officer Warrant System@{👮 Officer Warrant System}}
\label{md__r_e_a_d_m_e_autotoc_md0}%
\Hypertarget{md__r_e_a_d_m_e_autotoc_md0}%


A hybrid {\bfseries{Django + Django REST Framework}} application for managing police personnel and search warrants. This project allows for both web-\/based management (via Django Templates) and external integration (via REST API).

The entire development environment is containerized using {\bfseries{Docker}}, ensuring consistency across all developer machines.

\hypertarget{md__r_e_a_d_m_e_autotoc_md2}{}\doxysection{\texorpdfstring{🚀 Features}{🚀 Features}}\label{md__r_e_a_d_m_e_autotoc_md2}

\begin{DoxyItemize}
\item {\bfseries{Hybrid Architecture:\+}}
\item 🖥️ {\bfseries{Web Dashboard:\+}} Server-\/side rendered views using Django Templates.
\item 📡 {\bfseries{REST API:\+}} JSON endpoints for mobile apps or external integrations.
\item {\bfseries{Core Modules:\+}}
\item 👮 {\bfseries{Officers:\+}} Keep track of police personnel.
\item 📜 {\bfseries{Warrants:\+}} Create, track, and execute search warrants.
\item {\bfseries{Infrastructure:\+}}
\item 🐳 Fully Dockerized (No local Python installation required).
\item 🗄️ SQLite Database (File-\/based, persistent via Docker volumes).
\end{DoxyItemize}

\item the same process can be used to run the unit tests.
